# 🧠 LeetCode Solutions in C

My personal collection of optimized [LeetCode](https://leetcode.com/) solutions written in C. This repository tracks my progression in algorithms, data structures, and manual memory management.

## 🏗️ Structure

Problems are categorized by core concepts (e.g., Arrays, Pointers, Dynamic Programming). Each specific problem folder contains:
* `solution.c`: The primary source code.
* `README.md`: A brief breakdown of the time and space complexity (Big O).
